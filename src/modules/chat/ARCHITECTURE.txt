┌─ FLUJO DE EVENTOS ─────────────────────────────────────────────────────────┐
│                                                                            │
│  EVENTO: CONNECTION                                                       │
│  ─────────────────────────────────────────────────────────────────────   │
│  1. Cliente conecta con JWT token                                        │
│  2. handleConnection() extrae token                                      │
│  3. JwtService valida token                                              │
│  4. ✅ Válido → Almacena userId, userEmail en socket                   │
│  5. ❌ Inválido → client.disconnect(true)                               │
│  6. Emite 'connected' al cliente                                         │
│                                                                            │
│  EVENTO: joinProject                                                     │
│  ─────────────────────────────────────────────────────────────────────   │
│  1. Cliente emite { projectId: 'uuid-123' }                              │
│  2. Valida que projectId sea proporcionado                               │
│  3. Valida acceso con validateUserProjectAccess()                        │
│  4. ✅ Acceso OK → client.join(projectId)                               │
│  5. Carga historial con getProjectMessages()                            │
│  6. Emite 'joinedProject' con historial                                 │
│  7. Notifica a otros: 'userJoined'                                      │
│                                                                            │
│  EVENTO: sendMessage                                                     │
│  ─────────────────────────────────────────────────────────────────────   │
│  1. Cliente emite { content: '...', projectId: 'uuid-123' }            │
│  2. Valida DTO con class-validator                                       │
│  3. Verifica acceso del usuario al proyecto                              │
│  4. Guarda en BD con createMessage()                                     │
│  5. ✅ Éxito → Emite SOLO a sala: server.to(projectId).emit()          │
│  6. ❌ Error → Emite 'error' al cliente                                 │
│  7. Todos en sala reciben 'newMessage'                                  │
│                                                                            │
│  EVENTO: DISCONNECTION                                                   │
│  ─────────────────────────────────────────────────────────────────────   │
│  1. Socket se desconecta                                                 │
│  2. Notifica a todas las salas: 'userLeft'                              │
│  3. Remueve de connectedUsers map                                        │
│  4. Limpia referencias de projectsJoined                                 │
│  5. Libera memoria                                                        │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

│     └─ @MinLength(1) - Al menos 1 carácter                               │
│  └─ projectId:                                                           │
│     ├─ @IsString() - Debe ser texto                                      │
│     ├─ @IsNotEmpty() - No vacío                                          │
│     └─ @IsUUID('4') - UUID válido v4                                     │
│                                                                            │
│  ACCESS VALIDATION (validateUserProjectAccess)                           │
│  └─ Simula consulta: SELECT * FROM user_projects WHERE ...              │
│  └─ Retorna: boolean (acceso permitido o denegado)                       │
│                                                                            │
